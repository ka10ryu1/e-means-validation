# 許容幅の感度（補足の読み方）

同等品質の判定規則は「e-means の test MSE ≤ 基準の test MSE × 1.01」（[methodology.md](methodology.md) §5）。この規則は**変えていない**。
ここでは、既存の実行の生データ（`results/<run>/raw_results.csv`）から、同じ集計コード（`emv.analysis.compare`）で許容幅だけを 1% / 0.5% / 0.1% / 0% に変えて読み直した。新しい計測はしていない。

- 目的: 実データで手法間の MSE 差が 1% 程度しかなく、1% の判定が粗いという指摘（README §7）が、結論をどこまで左右するかを確かめる。
- 再現性の確認: スクリプトは、各実行に記録された許容幅（1%）での再計算が `reports/<run>/comparison.csv` と一致することを確かめてから表を出す。対象の 12 実行すべてで一致した。
- 対象: README §7 が速度の根拠にしている実行（Medium・Quick の夜間計測、規模を振った 8 実行、実データ 2 実行）。いずれも CPU の取り合いの検出 0 件。
- 規則の変更ではないので、過去のレポートとの比較可能性は変わらない。

```bash
uv run python make_tolerance_table.py \
    reports/speed_20261111-1905_medium_t4 reports/speed_20261111-2023_quick_t4 \
    reports/scale_20261112-0338_*_t4 \
    reports/speed_20261112-1333_sift1m_medium_t4 reports/speed_20261112-1333_deep1m_medium_t4
```

## 前提: 基準自体のシード間の幅

Lloyd25 / Lloyd++25 の test MSE の（最大 − 最小）÷ 中央値（`summary.csv` から）:

| データ | 幅 |
|---|---|
| sift1m / deep1m（medium） | 0.12〜0.23% |
| gaussian（medium、n1m、d16） | 0.04〜0.21% |
| imbalanced / separated（medium、n1m、d16） | 0.5〜18% |

実データと gaussian では、**0.1% と 0% の判定は基準自体のシード間の幅より細かい**。この 2 列の違いは中央値どうしのわずかな差で決まり、統計的に区別できる差ではない。人工データの imbalanced・separated はシードごとにデータ自体が変わるので幅が大きく、シード別到達数（括弧内）を併せて見る。

## 読み取れること

1. **実データでは、必要エポックは許容幅に敏感だが、「同手法最短より速い」という結論は変わらない。** 1% → 0.1% で、e-means が到達する最少エポックは 1〜2 → 3（deep1m の e-means++ は 2）に増える。同時に Lloyd も 5〜10 反復では足りず 25 反復が必要になるため、同手法最短比は 0.1% でむしろ上がる（sift1m: A 3.13→5.65×、B 2.66→3.68×、deep1m: A 3.54→5.89×、B 2.82→4.03×）。中間の 0.5% では、e-means++ は 1 → 2 エポックに増えるのに Lloyd++ は 10 反復のままなので、B は sift1m 2.66→2.08×、deep1m 2.82→2.05× に下がる（A は sift1m 3.13→3.31×、deep1m 3.54× で変わらず）。いずれの許容幅でも 1 倍を下回らない。
2. **人工データの gaussian・separated（d ≥ 64）は、0.1% まで最少エポックがほとんど変わらない**（k=4096 の separated の 2 エポックを除き、すべて 1 エポック）。0% にすると Lloyd が 25 反復を要する点が増え、倍率は基準そのものとの比に近づく（例: n1m separated A 18.2×）。
3. **1% でぎりぎり到達していた不均衡データの点は、狭めると未到達になる。** 公式デフォルトの e-means 対 Lloyd25 で、d=16 の imbalanced（1% で 10 エポック、0.296×）は 0.5% で、n=1M の imbalanced（1% で 10 エポック、0.764×）は 0.1% で未到達になった。1% で未到達だった点は、狭めても当然すべて未到達のまま。
4. **低次元（d ≤ 16）の例外的な点は 0.5% で消える。** README 解釈 9・10 で唯一 Lloyd より速かった d=2 の imbalanced の e-means++ 対 Lloyd++（1 エポック、1.02×）は、0.5% では 2 エポック必要になり 0.722× になる。d=16 の gaussian の e-means 対 Lloyd25 も 0.1% で 1 → 2 エポック、0.466× → 0.278× と遅くなる。一方 d=16 の separated の e-means 対 Lloyd25 は、Lloyd が 25 反復を要するようになるため 0.903× → 2.29×（0.5%）と逆転する。
5. **Lloyd の test MSE は反復とともに必ず下がるわけではない。** n=1M の gaussian では Lloyd 5 反復（54.0783）が 25 反復（54.0815）より低く、0% では「Lloyd は 5 反復で到達、e-means は 2 エポック必要」となって倍率が 3.64× → 1.95× に下がる。差は 0.006% で、0% 列の判定がこうした微差で決まる例である。

まとめ: 許容幅を狭めると、e-means と Lloyd の**両方**に追加の反復が必要になるので、同手法最短比は一方向には動かない。結論が許容幅で変わったのは、1% で境界付近にあった点（不均衡データの 10 エポック到達、d=2 の 1.02×、実データ B の 0.5%）に限られる。
